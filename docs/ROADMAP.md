# Roadmap

## Now: verify on a real board

Everything below passes on the mocked board (`test/smoke/mock-board.html`) and has not been checked on
real Miro. Use `docs/MIRO_SDK_NOTES.md` → "How to inspect on a real board". Fix whatever doesn't hold,
then move the item to "Verified" in that file.

- [ ] Panel opens and reads a real board. Note the timings in the stats tooltip (read ms, render ms, item count)
- [ ] Node types come out right (`decision`, `process`…), not `shape` or `stencil`
- [ ] Mermaid output renders on mermaid.live with the correct shapes
- [ ] Frames become sections, and notes attach to the right nodes (this validates the `relativeTo` handling)
- [ ] Edge direction is correct for arrows drawn "backwards" and for lines without arrowheads
- [ ] Board name has no "- Miro" or ", Online Whiteboard…" suffix
- [ ] Live mode: selecting is instant (no "busy" flash), and editing a shape's text updates the output without ↻
      (if not, `installWatcher` events don't work in the top frame: see MIRO_SDK_NOTES)
- [ ] Large board (500+ items): read time is acceptable, and polling doesn't make the board lag
- [ ] `Alt+Shift+C` is assigned on install, copies, and shows the toast
- [ ] Switching boards in the same tab (SPA navigation) refreshes the panel
- [ ] Download file name equals the board name (Cyrillic included)

## Backlog (v0.4+)

- Context-menu item "Copy flowchart for LLM"
- Mermaid preview inside the panel (render the diagram to check the export visually)
- Flowchart validation: dead ends, unreachable nodes, decisions with unlabeled branches (warnings in the panel)
- Presets: named bundles of format + template + options ("For Claude", "For docs", "JSON pipeline")
- ERD → SQL DDL export (Miro ERD templates; a real user request on the Miro forum)
- Incremental refresh: on an update event, re-read only the changed items, if the event payload allows it
- Copy from the panel with `Ctrl/Cmd+Enter`
- Optional real tokenizer for exact counts (only if it stays small and local)

## Article plan (Medium, itboom.dev)

Working title: *How to feed flowcharts to an LLM (and why Mermaid isn't the best format)*

1. The pain: Miro has no flowchart export, and the API returns `stencil` with no text
2. The investigation: unsupported items, the `experimental` namespace, `window.miro` in the top frame,
   coordinates relative to frames
3. The core insight: an adjacency list with short IDs, DFS order and explicit loops vs Mermaid vs JSON.
   Include a measured comparison: tokens per format on the same diagram, and LLM accuracy on questions
   such as "list all paths to Done" and "which branches are missing"
4. The tool: GIF, features, privacy (local only)
5. An honest comparison with the official Miro MCP: when to use which
6. A caveat: experimental API, "works as of November 2026"

Distribution: Medium, the Miro Community thread about reading stencils, r/ChatGPTPro, r/ClaudeAI, Product Hunt.
