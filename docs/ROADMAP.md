# Roadmap

## Done: verified on a real board (maintainer, 2026-11-22)

The maintainer confirmed the extension works on a real Miro board. The confirmation covered the list as a
whole, not each item separately, and the "Assumed" table in `docs/MIRO_SDK_NOTES.md` has not been updated
item by item. Re-run this list after any change to `src/extract.js`, and when Miro changes its SDK
(`docs/MIRO_SDK_NOTES.md` → "How to inspect on a real board").

- [x] Panel opens and reads a real board. Note the timings in the stats tooltip (read ms, render ms, item count)
- [x] Node types come out right (`decision`, `process`…), not `shape` or `stencil`
- [x] Mermaid output renders on mermaid.live with the correct shapes
- [x] Frames become sections, and notes attach to the right nodes (this validates the `relativeTo` handling)
- [x] Edge direction is correct for arrows drawn "backwards" and for lines without arrowheads
- [x] Board name has no "- Miro" or ", Online Whiteboard…" suffix
- [x] Live mode: selecting is instant (no "busy" flash), and editing a shape's text updates the output without ↻
      (if not, `installWatcher` events don't work in the top frame: see MIRO_SDK_NOTES)
- [x] Large board (500+ items): read time is acceptable, and polling doesn't make the board lag
- [x] `Alt+Shift+C` is assigned on install, copies, and shows the toast
- [x] Switching boards in the same tab (SPA navigation) refreshes the panel
- [x] Download file name equals the board name (Cyrillic included)

## Article plan (Medium, itboom.dev)

Working title: *How to feed flowcharts to an LLM (and why Mermaid isn't the best format)*

1. The pain: Miro has no flowchart export, and the API returns `stencil` with no text
2. The investigation: unsupported items, the `experimental` namespace, `window.miro` in the top frame,
   coordinates relative to frames
3. The core insight: an adjacency list with short IDs, DFS order and explicit loops vs Mermaid vs JSON.
   Include a measured comparison: tokens per format on the same diagram, and LLM accuracy on questions
   such as "list all paths to Done" and "which branches are missing"
4. The tool: GIF, features, privacy (local only)
5. An honest comparison with the official Miro MCP: when to use which
6. A caveat: experimental API, "works as of November 2026"

Distribution: Medium, the Miro Community thread about reading stencils, r/ChatGPTPro, r/ClaudeAI, Product Hunt.
