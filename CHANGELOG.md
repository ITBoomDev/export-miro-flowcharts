# Changelog

## Unreleased

### Added
- Extension icons (16/32/48/128), generated by the dependency-free `tools/icons.mjs`; wired into
  `manifest.json` (`icons` + `action.default_icon`).
- Type checking: `bun run typecheck` (tsc `checkJs` over `src/` with JSDoc, `chrome-types` and
  `types/globals.d.ts`). No build step — Chrome still loads the vanilla ES modules directly.

- `docs/PRIVACY.md` and `docs/STORE_LISTING.md`: privacy policy, single purpose, permission justifications.

### Changed
- Dev toolchain moved from npm/Node to Bun (`bun.lock`, scripts in `package.json`). Tests keep the
  `node:test` API and still run on Node 20+. Docs D11/D12 record the reasoning.
- `zip` script rewritten as the cross-platform, dependency-free `tools/zip.mjs` (the old one needed the
  Unix `zip` binary, absent on Windows). The archive now includes `icons/`.

## 0.3.0 (2026-11-21)

### Added
- The board name (from the tab title) appears in the panel, the export header, the `{{board_name}}`
  placeholder and the download file name.
- Interface in English, Ukrainian and Russian. The language is auto-detected from the browser and system
  locale, with a selector in the panel header. The output language follows the interface by default
  (configurable). Plurals use CLDR rules. Built-in templates are translated. Store listing in `_locales`.
- Read and render timings in the stats tooltip.
- An end-to-end smoke test (`npm run smoke`) with a mocked Miro board.

### Changed
- Performance: the board is read once (previously experimental and stable `get()` both ran). Selection
  changes re-render from cache with zero SDK calls. The board is re-read only on create, delete or update
  events. The poll interval went from 700 to 400 ms.
- Warnings and errors are structured codes, translated in the UI.
- Settings schema v3, with automatic migration from v0.2.

## 0.2.0 (2026-11-21)

### Added
- A side panel that replaces the popup and stays open while you work on the board.
- Live mode: the panel updates when the selection changes.
- `Alt+Shift+C` copies the selection with the current settings and shows a toast on the board.
- Prompt templates (4 built in, plus custom ones) with `{{flowchart}}`, `{{board_url}}` and `{{stats}}`.
- Output options: legend language, node types, notes, frames as sections or Mermaid subgraphs,
  Miro item IDs, Mermaid direction.
- A token estimate.

### Changed
- Permissions: a host permission for `miro.com/app/board/*` replaces `activeTab` (needed for live mode).

## 0.1.0 (2026-11-21)

- First version: a popup with LLM text (adjacency list) / Mermaid / JSON, selection or whole board,
  Copy and Download.
