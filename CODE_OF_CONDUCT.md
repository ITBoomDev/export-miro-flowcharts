# Code of Conduct

## Our pledge

We want participation in this project to be a respectful and harassment-free experience for everyone,
regardless of background, identity or experience level.

## Expected behavior

- Be respectful and constructive. Critique code and ideas, not people.
- Assume good faith, and ask when something is unclear.
- Accept feedback gracefully, and give it kindly.

## Unacceptable behavior

- Harassment, insults, discriminatory language or personal attacks.
- Publishing someone else's private information.
- Sustained disruption of discussions, or spam.

## Enforcement

Maintainers may edit, hide or remove comments, issues and pull requests that violate this code, and may
block repeat offenders. Report problems through a private
[security advisory](https://github.com/ITBoomDev/export-miro-flowcharts/security/advisories/new) or by
contacting the maintainers of the ITBoomDev organization on GitHub.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
